# Code-quality allowlist — explicit exemptions with mandatory sunset.
#
# Authoritative source: rules/code-quality-golden-rule.md § 4 (Allowlist mechanism).
#
# Each ACTIVE entry downgrades a finding by ONE severity level
# (HARD → SOFT_CAP, SOFT_CAP → SOFT_FLOOR). Expired entries (today > SUNSET)
# are IGNORED — the underlying finding re-fires at full severity.
#
# Format (one entry per line) — SIX pipe-separated fields:
#   ECOSYSTEM | FILE-PATH | FINDING-TYPE | SYMBOL-OR-LINE | REASON | SUNSET
#
# Where:
#   ECOSYSTEM     — one of: python, typescript, rust, go
#   FILE-PATH     — repo-relative path where the finding fires (e.g. internal/config/config.go)
#   FINDING-TYPE  — one of: dead_code, symbol_fab, orphan_export, mutation_low
#   SYMBOL-OR-LINE— the symbol the finding names (e.g. Secret.MarshalJSON)
#   REASON        — free-form justification. REQUIRED — an empty reason is rejected.
#   SUNSET        — ISO date (YYYY-MM-DD). MUST be ≤ 90 days from entry.
#
# The first four fields are exactly the `allowlist_key` the detectors build
# (`go|internal/config/config.go|dead_code|Secret.MarshalJSON`), which is how an entry is
# matched to a finding.
#
# This header used to document a four-field form (`IDENTIFIER | FILE:LINE | SUNSET |
# RATIONALE`) that the parser has never accepted, and so did
# `code-quality-golden-rule.md § 4`. Writing entries from the documentation produced
# `allowlist_malformed_entry` — which ABORTS allowlist processing, silently disabling every
# other exemption in the file. Corrected 2026-08-12 (B-257).
#
# Lines starting with `#` and blank lines are skipped.
# Whitespace around `|` is tolerated.
#
# Adding/modifying entries:
#   - REQUIRES CHANGELOG entry under `[Unreleased] § Changed`.
#   - REQUIRES ADR for HARD-level exemptions (`knowledge-base/adrs/`).
#
# A malformed entry triggers the `allowlist_malformed_entry` HARD finding and
# aborts allowlist processing for the current run.
#
# Empty allowlist is the default. Add entries only when the underlying issue
# cannot be fixed within the iteration AND the risk is documented.

# Example (commented):
# dead_code_unallowlisted_python | src/legacy/migrator.py:128 | 2026-09-01 | Legacy migration helper retained for v0.9 rollback path; remove after v1.0 release.
