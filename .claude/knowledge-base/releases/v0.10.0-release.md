## Scope

This release cuts the accumulated `[Unreleased]` of theo-cloud to `main`. It bundles, beyond M0:
the Platform API Gateway M6/M8 (Traefik unified edge + ForwardAuth + Model B broker) and the
billing/register/caddyfile fixes that were already on `develop`. The **M0 account-level tenancy**
slice is the milestone tracked by this release's ROADMAP flip.

## Deploy ordering (M0)

The binary's key lookup SELECTs `account_id`. The migrations `000034`–`000039` (repo **theo**) must be
applied (on `theo:main` / the running pg-cloud) **before** this binary serves traffic. If the column
is absent, auth fails **closed** (`ErrBackendUnavailable` → 503), never a silent breach. The deploy
runbook must sequence migrations-first. (Noted in the PR #90 body.)
