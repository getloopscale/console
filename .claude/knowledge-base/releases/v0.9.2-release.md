## Release notes (Fixed)

- F-4 correction — dashboard Memory sub-nav genuinely re-renders on click. v0.9.1's fix (react-router native `navigate(path,{viewTransition:true})`) was verified live in Chrome to be INSUFFICIENT (the unit test asserted the call shape, not the actual re-render). Root cause: /memory/* are lazy+Suspense routes with no Outlet; ANY View Transition wrapper snapshots the old DOM before the lazy chunk commits (React 19 + RR v7). Corrected to plain `navigate(path)`; verified live (Skills→Episodes re-render without reload). Unit test rewritten to guard against re-introducing any viewTransition wrapper.

## Honest disclosure (Rule 3)

v0.9.1 shipped a false-confident F-4 fix. The unit test (navigate call-shape assertion) passed but did not exercise the real render path (jsdom has no startViewTransition). The DEFINITIVE catch was driving the real Chrome in the live test. Lesson: UX re-render fixes require live-browser verification, not just a call-shape unit test.
