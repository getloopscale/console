## Scope

M1 — Broker per-Account-scoped mint (lazy validation): the per-tenant credential broker is now
Account-aware (`accountID` in the cache key, never to the data-plane — `workspace_id == tenantID`
preserved), and ForwardAuth rejects a cross-account credential with 403 (lazy validation; legacy
NULL-account keys skip the check; DB-error fails closed). Control-plane Go only — **no migration**;
depends on the M0 schema already on `main` (v0.10.0).
