## Summary

Billing moves from per-tenant to per-Account: `subscriptions` is account-scoped
(`UNIQUE(account_id)`), and every plan / project-cap / usage-metering resolver reads
the Account's single subscription via a `tenant → account` join. The Stripe customer
is per-Account with an account-scoped idempotency key. Data-plane and project-creation
behavior unchanged; active per-tenant quota enforcement descoped (engine, follow-up).

## Deploy ordering (REQUIRED)

Apply the `theo` migrations `000040`–`000043` to pg-cloud **before** rolling out this
binary — the resolvers SELECT `account_id`. If the column is absent (wrong order), auth
fails closed (`503`), never a silent breach.
