# Milestone M14 — System-wide standardized modal component (AppModal)

## Objective (from ROADMAP.md)

Make "modal" the system-wide standard for transient action screens by shipping ONE
reusable componentized modal (AppModal) built on the design-system Dialog, and route the
Wiki's action screens (New folder, New page, Search) through it.

## Outcome

Delivered end-to-end via the full cycle (discover → plan → implement TDD → code-quality →
review → benchmark → release). AppModal (`components/ui/app-modal.tsx`) wraps the Radix-based
Dialog with a size scale (sm/md/lg/xl) + title/description/body/footer, delegating all a11y.
NewFolderDialog (shared with Workspace) rebuilt on it with props/behavior preserved; the Wiki
New page moved out of the side pane into an AppModal; Search stays CommandPalette; reading
stays in the master-detail split.

Evidence: typecheck + eslint clean; full dashboard suite 236 files / 1788 tests green (17 new
across AppModal/NewFolderDialog/wiki + 4 review-driven edge-case tests); production build
green. Multi-agent review READY_TO_MERGE (EC2/EC3/EC5 gaps closed). LIVE on app-dev — the
edge serves the exact built bundle (entry hash index-1QlAmOZp.js matches). Benchmark: AppModal
608 B min / 387 B gzipped, 0 new deps; centralizes a ~12-line Dialog skeleton duplicated
across 20 ad-hoc sites. Released v0.56.0 (PR #224 self-merged; tag + GitHub release published).
